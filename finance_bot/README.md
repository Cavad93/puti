# 🤖 Финансовый Telegram Бот с AI

Умный помощник для управления личными финансами с интеграцией Claude API. Помогает выбраться из долгов, контролировать расходы и достичь финансовой свободы.

## ✨ Возможности

### 💳 Управление долгами
- **Кредиты и займы**: Добавление потребительских кредитов и микрозаймов
- **Кредитные карты**: Полный контроль над кредитными картами
- **Расчет процентов**: Автоматический расчет аннуитетных платежей и процентов
- **Досрочное погашение**: Калькулятор выгоды от досрочного погашения
- **Кредитные каникулы**: Учет и пересчет графика при каникулах
- **Стратегии погашения**: Методы "Снежный ком" и "Лавина"

### 💰 Учет доходов и расходов
- **Категории доходов**: Зарплата, подработка, пассивный доход и другие
- **Обязательные/необязательные расходы**: Разделение по типам
- **Регулярные расходы**: Автоматическое определение повторяющихся платежей
- **Статистика**: Детальная аналитика по всем операциям

### 🎯 Бюджетирование
- **Автоматическое создание**: AI формирует бюджет на основе ваших данных
- **Персонализация**: Учет предыдущих решений и особенностей пользователя
- **Контроль**: Строгие предупреждения при превышении бюджета
- **Цели**: Подушка безопасности = обязательные расходы × 6 месяцев

### 📊 Отчетность
- **Графики и таблицы**: Визуализация всех данных
- **Гибкие периоды**: Отчеты за любой период
- **Прогнозы**: Расчет времени до выхода из долгов
- **Экспорт**: Сохранение отчетов в виде изображений

### 🤖 AI-Советник (Claude)
- **Персональные рекомендации**: На основе ваших данных
- **Анализ расходов**: Поиск зон для оптимизации
- **Стратегии погашения**: Оптимальный план выхода из долгов
- **Финансовое планирование**: Помощь в достижении целей
- **Ежедневные советы**: При внесении новых данных

### ⏰ Напоминания
- **Ежедневно в 22:00 МСК**: Напоминание о внесении данных
- **Контроль дисциплины**: Мотивация вести учет регулярно

## 🚀 Установка

### Требования
- Python 3.9+
- Telegram аккаунт
- Claude API ключ
- VPS сервер (для постоянной работы)

### Шаг 1: Клонирование репозитория

```bash
git clone <your-repo>
cd finance_bot
```

### Шаг 2: Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 4: Настройка переменных окружения

1. Создайте Telegram бота через [@BotFather](https://t.me/BotFather)
2. Получите Claude API ключ на [console.anthropic.com](https://console.anthropic.com/)
3. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot)

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_from_botfather
CLAUDE_API_KEY=your_claude_api_key
ALLOWED_USER_IDS=123456789,987654321
DATABASE_PATH=finance_bot.db
TIMEZONE=Europe/Moscow
```

### Шаг 5: Запуск бота

```bash
python bot.py
```

## 📱 Использование

### Первый запуск

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Бот проверит доступ и покажет главное меню

### Основные команды

- `/start` - Запуск бота и приветствие
- `/help` - Справка по использованию
- `/menu` - Вызов главного меню

### Добавление кредита

1. **Главное меню** → `💳 Мои кредиты`
2. **Управление кредитами** → `➕ Добавить кредит/займ`
3. Выберите тип кредита
4. Введите данные:
   - Название кредита
   - Сумма кредита
   - Процентная ставка (%)
   - Ежемесячный платеж
   - Дата начала
   - День платежа

### Добавление расхода

1. **Главное меню** → `📊 Добавить расход`
2. Выберите тип:
   - ✅ Обязательные (продукты, коммуналка, транспорт...)
   - ⭐ Необязательные (развлечения, одежда, подарки...)
   - ❗ Незапланированные
3. Выберите категорию
4. Если обязательный - укажите, регулярный ли это расход
5. Введите сумму

### Добавление дохода

1. **Главное меню** → `💰 Добавить доход`
2. Выберите категорию (зарплата, подработка, пассивный доход...)
3. Введите сумму

### Получение отчета

1. **Главное меню** → `📈 Отчеты`
2. Выберите тип отчета
3. Выберите период или укажите свой
4. Получите отчет с графиками

### Работа с AI

1. **Главное меню** → `🤖 Спросить AI`
2. Выберите тип анализа:
   - 💡 Общий анализ ситуации
   - 📊 Анализ расходов
   - 🎯 Стратегия погашения долгов
   - 💰 Помощь с бюджетом
   - ❓ Свой вопрос
3. Получите персональные рекомендации

### Создание бюджета

1. **Главное меню** → `🎯 Бюджет`
2. **Управление бюджетом** → `🤖 Создать бюджет с AI`
3. AI проанализирует ваши данные и создаст оптимальный бюджет
4. Бюджет будет сохранен и использован для контроля расходов

## 🔧 Настройка на VPS

### Systemd сервис (Linux)

Создайте файл `/etc/systemd/system/finance-bot.service`:

```ini
[Unit]
Description=Finance Telegram Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/finance_bot
Environment="PATH=/path/to/finance_bot/venv/bin"
ExecStart=/path/to/finance_bot/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Запуск:

```bash
sudo systemctl enable finance-bot
sudo systemctl start finance-bot
sudo systemctl status finance-bot
```

### Логи

```bash
sudo journalctl -u finance-bot -f
```
