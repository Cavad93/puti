# 🤖 Финансовый Telegram Бот с Разговорным AI

Умный помощник для управления личными финансами через естественный диалог. Powered by Claude Sonnet 4.5 - просто пиши как обычному человеку!

## 🎯 Главная особенность

**БЕЗ КНОПОК И МЕНЮ** - управление полностью через разговор с AI:

```
Ты: 35000 на кредит в Сбере
AI: ✅ Платёж 35 000 руб по кредиту Сбербанк внесён. Остаток: 465 000 руб.

Ты: 590 за кофе
AI: ✅ Расход 590 руб (Развлечения) добавлен

Ты: У меня кредит в Альфе 300к под 16%
AI: Понял! Какой ежемесячный платеж?
Ты: 12000
AI: Когда взял кредит?
Ты: В январе 2024
AI: ✅ Кредит 'Альфа-Банк потребительский' добавлен

Ты: Это ошибка, удали
AI: ✅ Последняя транзакция удалена

Ты: Сколько я потратил на кофе?
AI: За последний месяц на кофе потрачено 12 450 руб (14% от всех расходов)
```

## ✨ Возможности

### 💬 Естественный диалог
- **Понимает обычный язык**: Пиши как удобно тебе
- **Запоминает контекст**: Помнит предыдущие сообщения
- **Различает кредиты**: Понимает несколько кредитов в одном банке
- **Уточняет при необходимости**: Если что-то непонятно - спросит
- **Исправляет ошибки**: "Это ошибка, удали" / "Измени сумму"

### 💳 Управление долгами
- **Кредиты и займы**: Потребительские кредиты и микрозаймы
- **Кредитные карты**: Полный контроль с расчётом процентов
- **Автоматические расчёты**: Аннуитетные платежи, проценты, графики
- **Досрочное погашение**: Калькулятор выгоды
- **Кредитные каникулы**: С пересчётом графика
- **Стратегии погашения**: "Снежный ком" и "Лавина"

### 💰 Учёт доходов и расходов
- **Категории**: Автоматическое определение
- **Обязательные/необязательные**: AI сам распределяет
- **Регулярные платежи**: AI спрашивает и запоминает
- **Статистика**: Детальный анализ

### 📊 Отчёты с графиками
- **По запросу**: "Покажи расходы за месяц"
- **С визуализацией**: Графики и таблицы
- **За любой период**: AI сам определит период
- **Автоматическая генерация**: Текст + изображения

### 🤖 AI-Помощник (Claude Sonnet 4.5)
- **Персональные советы**: На основе твоих данных
- **Финансовый анализ**: Поиск зон оптимизации
- **Стратегии выхода из долгов**: Конкретные планы
- **Бюджетирование**: Автоматическое создание
- **Мотивация**: Помогает не сдаваться

### ⏰ Напоминания
- **Ежедневно в 22:00 МСК**: "Что потратил сегодня?"
- **Без принуждения**: Просто напоминает

## 🚀 Установка

### Требования
- Python 3.9+
- Telegram
- Claude API ключ
- VPS сервер (опционально)

### Шаг 1: Клонирование

```bash
git clone <your-repo>
cd finance_bot
```

### Шаг 2: Виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### Шаг 3: Зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4: Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather)
2. Получи Claude API ключ: [console.anthropic.com](https://console.anthropic.com/)
3. Узнай свой Telegram ID: [@userinfobot](https://t.me/userinfobot)

Скопируй `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполни `.env`:

```env
TELEGRAM_BOT_TOKEN=your_bot_token
CLAUDE_API_KEY=your_claude_api_key
ALLOWED_USER_IDS=123456789,987654321
```

### Шаг 5: Запуск

```bash
python bot.py
```

### Как это работает

1. **Ты пишешь** обычное сообщение
2. **Claude Sonnet 4.5** понимает намерение
3. **AI-агент** вызывает нужные инструменты (tools)
4. **Инструменты** работают с БД
5. **Claude** формулирует понятный ответ
6. **Ты получаешь** результат + графики (если нужно)

## 🔧 Развёртывание на VPS

### Systemd сервис

Создай `/etc/systemd/system/finance-bot.service`:

```ini
[Unit]
Description=Finance AI Telegram Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/finance_bot
Environment="PATH=/path/to/finance_bot/venv/bin"
ExecStart=/path/to/finance_bot/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Запуск:

```bash
sudo systemctl enable finance-bot
sudo systemctl start finance-bot
sudo systemctl status finance-bot
```
